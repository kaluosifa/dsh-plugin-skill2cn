DSH 插件 开源 · MIT 一键可逆

Skill2CN 技能汉化

让英文技能描述 ⇢ 一键变中文，随时还原，即改即生效
核心功能
🌐

一键翻译

英文描述译成简体中文，直接写入磁盘、热刷新生效，无需重启 DSH

↩️

一键还原

原文全部备份在清单中，支持单条还原或「全部还原」，进可攻退可守

🔔

新技能提醒

安装新技能时右下角自动弹卡片询问是否翻译，再也不会漏掉新装的技能

🧭

模型自选路由

跟随会话 / 已配置模型 / 自定义 API 端点，三选一，附「测试」按钮即时验证

三步上手
1

打开面板

DSH 界面点 设置 → 技能汉化，在任意会话先发一条消息，让面板捕获模型路由

›
2

选择翻译

「未翻译」页挑一张卡片点 翻译，或点 全部翻译 批量处理（并发 3 个）

›
3

查看效果

「已翻译」页可 查看原文 对照、单条还原或全部还原，翻译即时生效

💡

两个要点：只翻译 description 一个字段，技能名与正文逐字节不动，改坏风险为零； 卸载插件前记得先点「全部还原」——译文不会随卸载自动复原。 中文描述的技能会被标记「无需翻译」，自动跳过。

dsh plugin --profile web add <插件路径> 面板入口：设置 · 技能汉化 · 未翻译 / 已翻译 / 模型设置

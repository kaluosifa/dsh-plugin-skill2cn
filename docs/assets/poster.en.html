Skill2CN Skill Localization

English skill descriptions ⇢ Simplified Chinese — one click, revertible anytime, effective immediately
CORE FEATURES
🌐

One-click Translate

English descriptions become Simplified Chinese, written straight to disk and hot-reloaded — no DSH restart needed

↩️

One-click Restore

Originals are all backed up in the ledger; restore a single entry or hit "Restore All" — fully reversible

🔔

New-skill Prompt

When a new skill appears, a card pops up in the bottom-right asking whether to translate — never miss one

🧭

Flexible Model Routing

Follow session / configured model / custom API endpoint — pick one of three, with a Test button to verify instantly

THREE STEPS
1

Open the Panel

In DSH go to Settings → Skill Localization, and send one message in any session so the panel captures the model route

›
2

Pick & Translate

On the Untranslated tab click Translate on a card, or Translate All to batch-process (concurrency 3)

›
3

See the Result

The Translated tab offers View original, single restore, or Restore All — translations take effect instantly

💡

Two key points: only the description field is translated — the skill name and body stay byte-for-byte intact, so there is zero breakage risk. And remember to click Restore All before uninstalling — translations are not reverted automatically. Skills already in Chinese are marked "no translation needed" and skipped.
